### 事项

将 02_Libraries 15 语言的 SRV 库身份解析，从旧 `id=;key=;nick=;ipfs=` 迁移到
**did:dns 三记录身份模型**：

```
did:dns:v=1;fp=<fp>;n=<nick>;g=<gender>;iat=<ts>;exp=<ts>   (声明，必填)
did:dns:pk;kty=ed25519;pk=<pubkey-base64url>                 (公钥，必填)
did:dns:black;fp=<fp1>,<fp2>,...                             (吊销列表，可选)
```

防篡改指纹链：`fp == Base64URL(SHA-256(pk)[0:12])`。

### 跨语言一致性（golden vector）

15 语言均用同一输入（仅替换实际跑通的语言实测，其余代码内置同向量）：

```
pk_bytes = 0x00..0x1f (32 字节, Ed25519 公钥长度)
→ pk_b64url = AAECAwQFBgcICQoLDA0ODxAREhMUFRYXGBkaGxwdHh8
→ fingerprint = Yw3NKWbEM2aRElRI  (16 chars, Base64URL(SHA-256(pk)[0:12]))
→ nickname n=QWxpY2U 解码 = "Alice"
→ SRV: http=alice.kirinnet.org:8080, ws=alice.kirinnet.org:8082
→ 指纹链成立, is_valid(now)=true
```

实跑的 Python/JS/Rust 三者结果完全一致（fp、chain、valid 均同）。
